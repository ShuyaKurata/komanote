# コマノート (KomaNote)

iPad + Apple Pencil で漫画を描くための、プロ向けペイントソフト風の漫画制作アプリです。
ブラウザ(Safari)で動く Web アプリ(PWA)で、ホーム画面に追加すると全画面のアプリとして使え、オフラインでも動きます。

**公開 URL: https://shuyakurata.github.io/komanote/**

## なぜ Web アプリ(PWA)なのか

- 開発環境に Xcode が無くてもビルド・動作確認ができる
- iPad の Safari は Pointer Events で Apple Pencil の筆圧(`pressure`)を取得できる
- 「ホーム画面に追加」で全画面のアプリとして起動でき、オフラインでも動く(Service Worker)
- 外部ライブラリなし・ビルド不要の素の HTML / CSS / JavaScript(ES Modules)

## 画面構成

```
┌ メニュー(ファイル/編集/選択範囲/レイヤー/ページ/表示/ヘルプ)+ コマンドバー ─────────┐
│ツ│ サブツール        │                               │ ナビゲーター  │
│ー│ ツールプロパティ  │          キャンバス           │ レイヤー      │
│ル│ カラー            │                               │               │
└ ページ管理(サムネイル) ─────────────────────────────────────────────┘
```

- Tab キーまたはコマンドバーのボタンで左右のパレットを隠せる
- iPad 縦向きなど幅が狭いときは、パレットは最初は隠れている。選択中のツールをもう一度タップすると開き、キャンバスに触れると閉じる

## 動かし方

### Mac で試す

```bash
python3 -m http.server 8080
```

ブラウザで `http://localhost:8080` を開きます。

### iPad で使う

Service Worker(オフライン動作)は **HTTPS か localhost** でしか有効にならないため、iPad で常用するには HTTPS で公開します。

1. iPad の Safari で https://shuyakurata.github.io/komanote/ を開く
2. (自分で公開し直す場合)このリポジトリを GitHub に置き、Settings → Pages で `main` ブランチの `/`(ルート)を公開する。ビルドは不要
3. 共有ボタン →「ホーム画面に追加」
4. ホーム画面のアイコンから起動すると全画面で動き、以降はオフラインでも起動できる

> 同じ Wi-Fi の Mac に `http://<MacのIP>:8080` でアクセスしても描けますが、その場合はオフライン動作しません。

## 仕組み(処理と保存の場所)

- **処理はすべて各端末のブラウザの中で行います。** GitHub Pages(サーバー)は HTML・CSS・JavaScript・アイコンといった静的ファイルを配るだけで、
  描画・保存・書き出しの処理はしません。利用者が増えてもサーバー側の処理は増えません
  (GitHub Pages の配信量の目安は月 100GB。アプリ一式は約 300KB で、一度開けば以後は端末内のキャッシュから起動します)
- **作品のデータはサーバーに送られません。** 各端末のブラウザ内(IndexedDB)にだけ保存されます

## データの保存について

- **自動保存(ブラウザ内)**: 描いた内容は数秒ごとに端末のブラウザ内(IndexedDB)へ保存されます。
  Safari のデータ消去・空き容量不足・機種変更などで消えることがあります
- **ファイルと連動して保存 🔗**: 作品をローカルの作品ファイル(.komanote)と結びつけると、編集するたびにそのファイルも自動で上書きされます。
  作品一覧で 🔗 が付いている作品が連動中です。作品ファイルから読み込んだ作品は、そのファイルと自動で連動します
  - ブラウザの File System Access API を使うため、**パソコンの Chrome・Edge などで動きます**
  - **iPad・iPhone の Safari は、Web アプリがファイルを自動で上書きする機能に対応していません**。そのため連動できず、🔗 も付きません。
    代わりに作品の ⓘ →「ファイルに書き出す」→「共有・ファイルに保存」で「ファイル」アプリに手動保存してください
    (Safari が対応すれば、アプリ側は変更なしで連動できるようになります)
- 作品一覧はサムネイル・名前・🔗 マークだけを表示します。ページ数や保存先などの詳細と操作(開く・連動・書き出し・名前変更・削除)は ⓘ か 🔗 を押すと出ます
- 詳しい説明はアプリの「保存について」(初回起動時にも 1 回表示)にあります

## ディレクトリ構成

```
index.html              画面の骨組み
manifest.webmanifest    PWA の設定
sw.js                   オフライン用 Service Worker(ネットワーク優先・失敗時はキャッシュ)
icons/                  アプリアイコン
css/style.css           スタイル(ダークテーマ)
js/main.js              起動・作品一覧・新規作成
js/editor.js            エディタ本体(表示・入力・ジェスチャー・レイヤー/ページ操作・取り消し・保存)
js/ui.js                パレット類(メニュー・ツール・プロパティ・カラー・ナビゲーター・レイヤー・ページ管理)
js/tooldefs.js          ツール・サブツールと設定項目の定義
js/tools.js             基本ツール(手のひら・ブラシ・スポイト)とツールの登録
js/brush.js             ブラシエンジン(筆圧・手ブレ補正・入り抜き)
js/panels.js            コマ枠(テンプレート・描画・コマ枠ツール)
js/geometry.js          多角形の分割などの幾何計算
js/text.js              縦書き/横書きの組版とフキダシの描画
js/text-tools.js        テキスト・フキダシ・操作ツール
js/effects.js           塗りつぶし・網点トーン・集中線・流線
js/paint-tools.js       塗りつぶし・選択範囲・変形・図形ツール
js/export.js            PNG/JPEG/PDF/ZIP の書き出し、作品ファイルの保存・読み込み
js/notice.js            「データの保存について」の説明
js/filelink.js          ローカルの作品ファイルとの連動(自動上書き)
js/render.js            ページの描画(画面・サムネイル・書き出しで共通)
js/model.js             作品データの構造
js/paper.js             用紙サイズのプリセット
js/storage.js           IndexedDB への保存
js/history.js           取り消し/やり直し
js/dialog.js            ダイアログ・通知
docs/DEVLOG.md          開発作業の記録
```

## 開発の進め方

- `main` ブランチは常に動く状態を保つ
- 機能ごとに `feature/〇〇` ブランチを切って作業し、`--no-ff` でマージする
- 作業内容は [docs/DEVLOG.md](docs/DEVLOG.md) に記録していく
