## 2026-11-16 プロジェクト開始(`main`)

### やったこと
- git リポジトリを作成
- README(目的・機能一覧・構成・開発ルール)とこの開発ログを作成
- `.gitignore` を追加

### 判断したこと
- **ネイティブ(Swift)ではなく Web アプリ(PWA)で作る。**
  開発機に Xcode が入っておらずネイティブアプリをビルドできないため。
  iPad Safari は Pointer Events で Apple Pencil の筆圧を取れるので、描画アプリとして十分に使える。
- **外部ライブラリ・ビルドツールなし**で書く。オフラインで確実に動かすため、また構成を単純にするため。
- **作業解像度は既定 200dpi。** B4 を 600dpi にすると 1 レイヤーで約 200MB になり iPad の Safari ではメモリが足りない。
  200dpi なら B4 で約 23MB/レイヤーに収まる。原稿作成時に 150/300dpi も選べる。
- ブランチ運用: 機能ごとに `feature/*` を切り、完成したら `main` に `--no-ff` でマージする。

## 2026-11-16 エディタの基本部分(`feature/core-editor`)

方針変更: ユーザーから「有料版クリスタ(EX)みたいな感じに」と要望があったので、
画面構成と機能をプロ向けペイントソフト風に寄せる(ブランチ名も `feature/canvas-and-pages` から変更)。

### やったこと
- **画面構成**: 暗い色の UI。上にメニューバーとコマンドバー、左にツール・サブツール・ツールプロパティ・カラー、
  右にナビゲーター・レイヤー、下にページ管理。Tab で左右のパレットを隠せる。幅が狭い iPad 縦向きではパレットをキャンバスに重ねて表示
- **作品一覧(ホーム)**: 新規作成(用紙プリセット・解像度・ページ数)、開く、名前変更、削除
- **ブラシエンジン** (`js/brush.js`)
  - 筆圧でサイズが変わる、手ブレ補正(遅延追従方式)、入り・抜き
  - 1 ストロークを一時バッファに描いてから合成するので、半透明のペンでも重なった部分が濃くならない
  - 鉛筆はざらつき(グレイン)、エアブラシはぼかしスタンプ
  - サブツール: Gペン / 丸ペン / カブラペン / ミリペン / 鉛筆 / シャープペンシル / ラフ鉛筆 / 筆 / ベタ塗り用 / エアブラシ / 消しゴム3種
- **カラー**: メイン/サブカラー、透明色(描くと消える)、HSV ピッカー、よく使う色、最近使った色、スポイト
- **レイヤー**: 追加・下書きレイヤー・複製・下と結合・並べ替え・削除・表示/ロック・不透明度・合成モード(乗算など)
- **表示**: ピンチで拡大・回転、2 本指で移動、左右反転、ナビゲーター(縮小図・拡大率・回転)
- **ジェスチャー**: 2 本指タップで取り消し、3 本指タップでやり直し。Pencil を使うと指は自動で移動専用になる(設定で変更可)
- **取り消し/やり直し**: 変更範囲だけを保存。メモリ上限(約 320MB)を超えたら古い履歴から捨てる
- **ページ管理**: 追加・複製・削除・並べ替え・サムネイル
- **保存**: IndexedDB に自動保存(2.5 秒後)。開いているページのレイヤーだけをメモリに載せる

### 判断したこと
- レイヤーの画素は PNG Blob としてページ単位で読み書きする。全ページを常にメモリに載せると iPad Safari が落ちるため
- 描画中のストロークはレイヤーを直接書き換え、開始時の内容を退避しておく方式にした。取り消し用の差分を作るのが楽で、2 本指ジェスチャーに切り替わったときもストロークを取り消せる
- キーボードショートカットは一般的なペイントソフトに合わせた(P ペン、E 消しゴム、[ ] でサイズ、⌘Z など)

### 動作確認
- ブラウザで新規作成 → 描画 → 取り消し → 自動保存 → 再読み込みで内容が戻ることを確認

## 2026-11-16 コマ割り(`feature/panel-layout`)

### やったこと
- **コマ枠ツール**(K キー)を追加。サブツールは 3 つ
  - コマ枠カット: 線を引くと、その線が通るコマを 2 つに分ける。斜めの線でも分けられる
  - 長方形コマ: ドラッグでコマを作る
  - コマ枠の編集: コマを選んで移動・頂点を動かす・削除(Delete キー)
- **コマの間隔は自動**: 横向きの線で分けると「上下の間隔」、縦向きの線だと「左右の間隔」(初期値 5mm / 2mm)
- 線の角度を水平・垂直・45° に吸着する(オン/オフ可)
- **テンプレート**: 1コマ / 2段 / 3段 / 4段(4コマ) / 田の字 / 3段・中段2分割。新規作成時に選ぶと、後から追加したページにも使われる
- ツールプロパティで枠線の太さ・間隔を mm 単位で変更できる
- **コマの外側を白で隠す**: コマからはみ出した絵を隠す(オフにすれば枠外にも描ける)
- レイヤーパレットの一番上に「コマ枠」の行(表示/非表示、コマ数)
- コマの変更も取り消し/やり直しできる

### 判断したこと
- コマは「多角形の頂点リスト」で持つ。分割は半平面で凸多角形を切る方法(Sutherland–Hodgman)で行い、
  分割線から間隔の半分ずつずらした 2 つの半平面で切ることで、すき間を作っている
- コマ枠はラスターレイヤーの上に描く(絵の上に枠線が乗る)。コマごとにレイヤーフォルダでマスクする方式は
  操作が複雑になるので見送り、ページ全体で「コマの外側を白で隠す」方式にした

### 動作確認
- 新規作成(1コマテンプレート)→ 水平に分割 → 上段を斜めに分割 → 再読み込みで 3 コマが残ることを確認

## 2026-11-16 テキスト・フキダシ(`feature/text-balloon`)

### やったこと
- **テキストツール**(T キー): タップした位置に文字を置く。既存の文字をタップすると編集
- **フキダシツール**(F キー): 楕円 / 角丸 / ナレーション(長方形) / 思考(雲) / 叫び(トゲ)。
  タップで標準サイズ、ドラッグで好きな大きさに作れる。「しっぽを付ける」はフキダシの中から引っぱる
- **操作ツール**(O キー): テキスト・フキダシを選択して移動、四隅で拡大縮小、オレンジの点でしっぽを移動。
  選択中のものをもう一度タップすると文字を編集。Delete で削除、前面/背面へ
- 選択中のフキダシはツールプロパティから、フォント・文字サイズ(pt)・縦書き・太字・行間・白フチ・文字色・形・線の太さ・しっぽの太さを変えられる
- **縦書き組版**: 列は右から左、長音や「…」・括弧は 90° 回転、句読点は右上、小さい「っゃゅょ」は少し右上、
  2 桁の数字や「!?」は縦中横(1 マスに横並び)
- **アンチック風フォント**: 漫画のセリフでよく使う「かなは明朝、漢字はゴシック」を文字ごとにフォントを切り替えて再現
- レイヤーパレットに「テキスト・フキダシ」の行(表示/非表示)

### 判断したこと
- フキダシとしっぽは「2 倍の太さで線を描く → 白で塗る」の順で描き、本体としっぽの継ぎ目を消している
  (パスを結合すると回転方向によって重なり部分が抜けることがあるため)
- 文字を変えるとフキダシの大きさを自動で合わせる。手でサイズを変えたら自動調整をやめる(「文字に合わせる」で戻せる)
- スライダーで連続して変えたときは、止まってから 1 回だけ取り消し履歴に積む(`editor.live()`)

### 動作確認
- 楕円フキダシに 2 行のセリフ(「!?」「…」「っ」を含む)を入れ、縦書き・縦中横・アンチック風で表示されることを確認

## 2026-11-17 塗りつぶし・トーン・選択範囲・効果線(`feature/fill-tone-effects`)

### やったこと
- **塗りつぶしツール**(G キー)
  - 他レイヤーを参照: 見えている絵・コマ枠・フキダシを境界にして塗る(線画レイヤーと塗りレイヤーを分けられる)
  - 編集レイヤーのみ参照 / 囲って塗る(投げ縄で囲んだ範囲を塗る)
  - 色の誤差・領域拡縮(線との境目の隙間を埋める)
  - **トーン(網点)**: 線数・濃度・角度を指定。網点はページの原点にそろえるので、何度貼っても点がずれない
- **選択範囲ツール**(M キー): 長方形 / 投げ縄。選択中はペン・塗りが選択範囲内だけに効く
  - キャンバス上部に「選択解除 / 消去 / 塗りつぶし / トーン / 変形」のバーを表示
  - 「トーン」は新しいレイヤーを作ってそこに網点を貼る
- **変形**(⌘T): 選択範囲(なければレイヤーの描いてある範囲)を移動・拡大縮小・回転・反転。Enter で確定、Esc でキャンセル
- **図形・効果線ツール**(U キー): 直線 / 長方形 / 楕円 / **集中線** / **流線**
  - 集中線: 中心からドラッグして空白部分の大きさを決める。本数・線の太さ・ばらつきを設定できる
  - 効果線は、選択範囲 → 押した位置のコマ → ページ全体 の順に描く範囲を決める(コマの中で使うとコマからはみ出さない)

### 判断したこと
- 塗りつぶしはスキャンライン方式。B5・200dpi(約 350 万画素)で実用的な速さ
- 変形中は元の画素をレイヤーから切り取り、表示のときだけ変形した画像を重ねる。確定時にレイヤーへ描き込み、
  変形前のレイヤー全体を取り消し用に持っておく
- 塗り方の設定(線数・濃度・角度)はサブツールごとに覚える。メニューの「選択範囲にトーンを貼る」は「トーン(網点)を貼る」サブツールの設定を使う

### 動作確認
- 下段のコマに集中線を描き、コマ内に収まることを確認
- 上段左のコマをトーンで塗り、コマ枠で止まることを確認
- 長方形選択 → 変形 → 移動 → Enter で確定 → 取り消しで元に戻ることを確認

## 2026-11-17 書き出し・PWA 対応・iPad 縦向きの調整(`feature/export-pwa`)

### やったこと
- **書き出し**(ファイル → 画像・PDF の書き出し、⇧⌘E、コマンドバーの「書き出し」)
  - 形式: PNG / JPEG / PDF。ページ: このページ / 全ページ
  - 出力範囲: キャンバス全体 / 裁ち落としまで(入稿向け) / 仕上がりサイズ(Web 向け)
  - 全ページの PNG/JPEG は ZIP にまとめる。下書きレイヤーとガイドは書き出さない
  - iPad では共有シート(「ファイルに保存」など)にも渡せる
- **作品ファイル(.komanote)**: レイヤーの画素を含めた 1 ファイルで保存・読み込み(バックアップ・別端末への移動用)
- **PWA**: `manifest.webmanifest`・アプリアイコン・`sw.js` を追加。ホーム画面に追加すると全画面で起動し、オフラインでも動く
- **iPad 縦向き**: 幅が狭いときはパレットを最初から隠す。選択中のツールをもう一度タップで開き、キャンバスに触れると閉じる
- README を最新の機能・使い方・ショートカットに更新

### 判断したこと
- PDF と ZIP は外部ライブラリを使わず最小限の形式を自前で組み立てた(PDF は各ページに JPEG を 1 枚貼る形)。
  PDF のページサイズは出力範囲の実寸(mm → pt)にしてある
- Service Worker は「ネットワーク優先、失敗したらキャッシュ」。更新がすぐ反映され、オフラインでも起動できる
- 開いていないページを書き出すときは、そのページのレイヤーだけを一時的に読み込んで、終わったら解放する

### 動作確認
- PDF・ZIP を生成し、PDF は macOS で開けること(sips で PNG に変換できること)、ZIP は Python の zipfile で読めることを確認
- 画面から「PDF・このページ・仕上がりサイズ」で書き出し → 完了ダイアログ(712KB)まで確認
- 作品ファイルを作って読み込み → コマ 3 つ・フキダシ 1 つ・レイヤー画素が復元されることを確認
- iPad 縦向き相当(820×1180)でパレットが隠れ、キャンバスが全面に表示されることを確認
